# FitBuddy - AI Fitness Plan Generator

FitBuddy is an AI-powered fitness app that generates personalized workout plans using Google Gemini AI.

## Features
- Generates original workout plan using Gemini API
- Gives nutrition tips
- Allows user to give feedback and update the plan
- Saves user history

## Tech Stack
- Python, FastAPI
- Gemini API
- SQLite Database
- HTML, CSS, JS

## How to Run
1. pip install -r requirements.txt
2. Create .env file and add GEMINI_API_KEY=your_key
3. uvicorn app.main:app --reload
